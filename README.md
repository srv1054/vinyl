## Suggested values

- **Format:** LP, EP, 7", 10", 12", box set
- **Weight:** Enter the pressing weight in grams, such as 180.
- **Condition:** Mint, Near Mint, Very Good Plus, Very Good, Good, Poor
- **Notes:** Use for details that matter to you, such as colored vinyl, signed copies, or where the record is stored.
